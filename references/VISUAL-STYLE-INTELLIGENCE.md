# VISUAL STYLE INTELLIGENCE

A practical style-selection guide for MasL AI Image Art Director. Styles are references and design vocabularies—not presets to apply blindly. Select a style because it supports the message, audience, category, and constraints.

## Operating rules

1. **Start from communication, not style names.** Define message, audience, focal point, and format first.
2. **Choose one primary style direction.** A secondary influence is allowed only when compatible and intentional.
3. **Translate style into observable traits.** Specify layout, typography, palette, contrast, texture, imagery, and density; do not rely on a label alone.
4. **Avoid style soup.** Do not combine unrelated aesthetics (e.g. Swiss grid + Memphis shapes + cinematic neon) without a clear rationale.
5. **Use references responsibly.** Treat named movements as broad design language, not a request to copy a specific designer or existing artwork.
6. **Keep content legible and accurate.** Aesthetic treatment must not undermine hierarchy, text, or facts.
7. **When direction is unclear, offer 2–4 concise style options** with short explanations and a recommended choice. If the brief is complete, select internally and generate without unnecessary approval.

## Style library

### 1. Swiss / International Typographic Style
- **Traits:** strict grid, asymmetric balance, sans-serif typography, clear hierarchy, generous whitespace, restrained palette.
- **Works for:** educational visuals, one-pagers, editorial graphics, event posters, professional social posts.
- **Watch out:** can become sterile or overly corporate; maintain a strong visual idea.

### 2. Editorial / Magazine
- **Traits:** expressive headline hierarchy, intentional image/text interplay, refined spacing, art-directed photography, restrained details.
- **Works for:** editorial key visuals, covers, statement graphics, thought leadership.
- **Watch out:** don't imitate a particular publication's exact identity or overuse decorative serif type.

### 3. Minimalist
- **Traits:** few elements, deliberate whitespace, limited palette, simple geometry, strong focal point.
- **Works for:** quote cards, premium announcements, covers, product/feature graphics.
- **Watch out:** minimal does not mean empty, low-information, or generic.

### 4. Brutalist / Neo-Brutalist Graphic
- **Traits:** bold type, hard contrast, raw geometry, visible grid, block colors, deliberate tension.
- **Works for:** provocative statements, campaign posters, youth-oriented announcements, strong opinion graphics.
- **Watch out:** distinguish intentional rawness from poor alignment, clutter, or illegibility.

### 5. Swiss Modern / Contemporary Corporate
- **Traits:** clean grid, crisp sans typography, structured information, disciplined color accents, precise spacing.
- **Works for:** business announcements, product features, event graphics, professional explainers.
- **Watch out:** avoid stock-template sameness and generic gradient backgrounds.

### 6. Neo-Memphis
- **Traits:** playful geometric shapes, vivid colors, patterns, energetic composition, friendly forms.
- **Works for:** approachable education, creative events, playful social graphics.
- **Watch out:** limit shapes and colors; do not let decoration overpower the message.

### 7. Retro / Vintage
- **Traits:** period-inspired palette, print textures, typography, illustration or photographic treatment.
- **Works for:** nostalgic campaigns, themed events, covers, storytelling.
- **Watch out:** define a period or visual cues; avoid random “old paper” filters and fake distress.

### 8. Mid-Century Modern
- **Traits:** organic geometry, restrained retro palette, clean composition, simplified forms, optimistic tone.
- **Works for:** educational graphics, cultural events, conceptual posters.
- **Watch out:** avoid using it as a generic retro label without actual design cues.

### 9. Swiss Editorial / Newspaper
- **Traits:** dense but disciplined columns, strong typographic hierarchy, monochrome or limited color, information-led layout.
- **Works for:** editorial statement cards, issue explainers, data-led one-pagers.
- **Watch out:** keep text readable; don't add fake newspaper copy or pseudo-letters.

### 10. Typographic Poster
- **Traits:** typography is the main image; scale, line breaks, spacing, and contrast create impact.
- **Works for:** quotes, announcements, provocative statements, event posters.
- **Watch out:** exact copy and spelling are critical; prefer external typesetting when text must be flawless.

### 11. Photographic / Documentary Editorial
- **Traits:** believable light, candid or purposeful framing, natural materials, realistic context, restrained grading.
- **Works for:** educational visuals, storytelling, editorial key visuals, credible campaigns.
- **Watch out:** never present fabricated scenes as documentary evidence; avoid stock-photo clichés.

### 12. Cinematic / Filmic
- **Traits:** controlled lighting, deliberate depth, dramatic framing, coherent color treatment, atmospheric but purposeful.
- **Works for:** narrative posters, storytelling, selected campaign visuals.
- **Watch out:** “cinematic” is not permission for flares, haze, teal-orange grading, or spectacle by default. Describe specifics.

### 13. Conceptual / Surreal
- **Traits:** unexpected scale, symbolic juxtaposition, impossible but coherent scenes, visual metaphor.
- **Works for:** abstract technology concepts, editorial campaigns, thought-provoking visuals.
- **Watch out:** metaphor must remain understandable; avoid random surreal objects.

### 14. Infographic / Information Design
- **Traits:** clear data hierarchy, consistent visual encoding, labels, restrained iconography, modular layout.
- **Works for:** educational visuals, one-pagers, explainers, factual comparisons.
- **Watch out:** accuracy first; no invented values, misleading scale, or chart decoration.

### 15. Flat Vector / Geometric Illustration
- **Traits:** simplified shapes, clean edges, limited palette, consistent stroke/shape language.
- **Works for:** education, friendly explainers, simple conceptual visuals.
- **Watch out:** keep it coherent; avoid generic clip-art or unnecessary gradients.

### 16. Paper Cut / Collage
- **Traits:** layered paper shapes, visible edges, tactile shadows, handcrafted composition.
- **Works for:** storytelling, creative education, event posters, conceptual visuals.
- **Watch out:** keep material logic consistent; avoid fake 3D depth everywhere.

### 17. Risograph / Printmaking-Inspired
- **Traits:** limited ink colors, grain, slight registration character, bold shapes, print texture.
- **Works for:** cultural events, expressive posters, editorial/social graphics.
- **Watch out:** texture should be subtle enough for readability; don't simulate errors that obscure text.

### 18. Handcrafted / Organic
- **Traits:** natural irregularity, hand-drawn marks, organic forms, tactile materials.
- **Works for:** human-centered education, community events, warm storytelling.
- **Watch out:** brush/script typography is not automatically appropriate; preserve deliberate hierarchy.

### 19. 3D Graphic / Sculptural
- **Traits:** clearly art-directed objects, coherent material, controlled lighting, simple environment, strong silhouette.
- **Works for:** feature graphics, conceptual posters, modern campaign visuals.
- **Watch out:** avoid plastic-looking generic renders, excessive reflections, floating clutter, and gratuitous gloss.

### 20. Premium / Luxury Editorial
- **Traits:** restraint, precise spacing, refined materials, controlled contrast, selective detail, quiet confidence.
- **Works for:** premium covers, product announcements, sophisticated campaigns.
- **Watch out:** “premium” is not merely black-and-gold, serif fonts, or metallic effects.

### 21. Playful / Pop Graphic
- **Traits:** energetic shapes, bright but controlled palette, bold type, expressive composition.
- **Works for:** accessible education, youth events, upbeat social graphics.
- **Watch out:** maintain a clear focal point; avoid visual noise.

### 22. Dark Tech / Cyber Editorial
- **Traits:** dark field, controlled luminous accents, technical structure, restrained data motifs, high contrast.
- **Works for:** cybersecurity, AI/technology explainers, product feature visuals.
- **Watch out:** no default neon circuit boards, random HUDs, glowing brains, or fake code.

## Style selection matrix (quick guide)

| Need | Useful direction |
|---|---|
| Clarity and structured information | Swiss / Information Design |
| Thought leadership or editorial impact | Editorial / Swiss Editorial |
| Strong statement with few words | Typographic Poster / Brutalist |
| Friendly and accessible learning | Neo-Memphis / Flat Vector |
| Credible human context | Documentary Editorial |
| Emotional single-frame story | Photographic / Cinematic (restrained) |
| Abstract concept | Conceptual / Surreal |
| Tactile, handmade character | Paper Cut / Risograph / Organic |
| Premium restraint | Minimalist / Premium Editorial |
| Technology topic | Dark Tech only when justified; otherwise Editorial or Information Design |

## How to express a style in a generation prompt

Do not write only: “Swiss style” or “premium cinematic”.

Instead, specify the relevant visual traits. Example:

> Asymmetric editorial grid, large clean sans-serif headline, one restrained accent color, generous whitespace, sharply cropped documentary photograph, crisp alignment, no ornamental icons, no gradient glow.

For a different direction:

> Brutalist poster composition, oversized condensed headline, hard black-and-acid-yellow contrast, raw geometric blocks, intentionally off-center balance, limited supporting copy, no decorative texture.

Use a short, concrete style description. Include only traits that matter for the current image.

## Final check

Before generation, ask internally:
- Does this style reinforce the message?
- Can its defining traits be described concretely?
- Is the style appropriate for the audience and platform?
- Is it restrained enough to preserve clarity?
- Are any style clichés being added without purpose?
