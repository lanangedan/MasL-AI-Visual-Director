# Layout Index — MasL Visual Director

Use this index to retrieve and choose a layout archetype. Treat every wireframe as an adaptable structural reference, not a fixed template.

## Archetypes

| ID | Name | Primary use | Structure | Content density |
|---|---|---|---|---|
| LA-01 | Poster / Hero Visual | Awareness, campaign, event | Headline → dominant visual → subheadline → footer | Low–medium |
| LA-02 | Educational / Information Poster | Education, safety, explainers | Headline → claim → central visual + supporting facts → CTA/footer | Medium |
| LA-03 | Product Ad / Center Hero | Product/features advertising | Optional logo → headline → product hero + side details → offer/CTA | Low–medium |
| LA-04 | Food / Promo Visual | Food, menu, offer | Headline/promise → food hero → description/price → CTA | Low–medium |
| LA-05 | Editorial / Multi-Visual | Editorial, story, feature summary | Headline → asymmetric visual/text grid → payoff → footer | Medium–high |

## Quick selection

- **One message, one strong visual:** LA-01
- **Several facts around a central concept:** LA-02
- **Product must be the hero:** LA-03
- **Food or offer must trigger appetite/action:** LA-04
- **Several scenes or points need a reading sequence:** LA-05

## Retrieval behavior

When a brief arrives:
1. Identify communication goal, audience, content density, assets, CTA, and canvas ratio.
2. Select one archetype (or explain a purposeful hybrid internally).
3. Adapt proportions and omit unnecessary blocks.
4. Use the layout together with—not instead of—Visual Style Intelligence.
5. Generate and QA. Do not ask for approval if the brief is complete and the choice is low-risk.
