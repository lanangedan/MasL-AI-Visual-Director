# Layout Index — MasL Visual Director (21 Archetypes)

Use this index to retrieve and choose a layout archetype. Wireframes are adaptable structural references—not fixed templates. IDs LA-01–LA-21 correspond to the numbered frames in `MasL-Layout-Archetype-Library-21.drawio`.

## Quick retrieval by intent

- One message + one strong focal visual: **LA-01 / LA-21**
- Teach several facts: **LA-02 / LA-11 / LA-16 / LA-18**
- Product must dominate: **LA-03 / LA-08 / LA-15**
- Food or offer: **LA-04**
- Multiple scenes / narrative sequence: **LA-05 / LA-10**
- Person/product with copy beside it: **LA-06**
- Image first, information below: **LA-07**
- Two benefits/features: **LA-09**
- Strong opinion or quote: **LA-12**
- Simple headline–visual–description: **LA-13**
- Brand-forward campaign: **LA-14 / LA-19**
- Central metaphor/illustration: **LA-17**
- App/site/software showcase: **LA-20**

## Selection workflow

1. Identify communication goal, audience, core message, content density, available assets, CTA, and canvas ratio.
2. Select the best matching archetype from the catalog; use a purposeful hybrid only when a single structure cannot serve the brief.
3. Adapt proportions, reading order, and omit blocks that are not needed.
4. Pair layout with Visual Style Intelligence; layout does not dictate style.
5. Generate and QA. Do not ask for approval when the brief is complete and the choice is low-risk.
